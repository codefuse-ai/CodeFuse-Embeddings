# Ray分布式训练支持功能文档

## 1. 新增核心功能说明及实现方式

### 1.1 完整的Ray检查点保存机制

**功能说明**：
实现符合Ray最新API规范的检查点保存和加载机制，解决原始实现使用已弃用API导致的警告信息和功能不完整问题。

**实现方式**：
1. 修改`ray_utils.py`中的`save_ray_checkpoint`和`load_ray_checkpoint`函数
2. 使用Ray推荐的目录方式保存检查点，替代已弃用的`from_dict()`方法
3. 实现完整的检查点版本管理机制，支持模型状态、优化器状态和学习率调度器状态的保存

### 1.2 多节点集群训练支持

**功能说明**：
扩展原始单机训练实现，支持跨多个节点的分布式训练，提高训练规模和效率。

**实现方式**：
1. 修改`ray_train.py`以支持集群模式连接
2. 实现跨节点数据分发机制，根据工作节点索引分发训练文件
3. 增加集群状态监控功能，实时报告资源使用情况
4. 支持自动集群发现和手动指定集群地址两种模式

### 1.3 多GPU训练支持

**功能说明**：
增强原始单GPU训练实现，支持单机多GPU并行训练，充分利用硬件资源。

**实现方式**：
1. 修改`model.py`中的`F2LLM`类以支持多GPU训练
2. 实现GPU资源管理和分布式数据并行
3. 优化模型前向和反向传播过程
4. 支持动态GPU资源分配和故障检测

### 1.4 环境兼容性优化

**功能说明**：
解决训练过程中的各种环境兼容性问题，确保在不同环境下稳定运行。

**实现方式**：
1. 设置环境变量`TOKENIZERS_PARALLELISM=false`和`TORCH_DISTRIBUTED_ELASTIC_LOG_LEVEL=ERROR`减少警告信息
2. 配置运行时环境排除大型文件，解决工作目录大小限制问题
3. 动态配置资源，根据是否使用GPU来决定资源分配
4. 修复BERT模型的Flash Attention兼容性问题

### 1.5 检查点恢复训练支持

**功能说明**：
实现训练中断后的检查点恢复功能，允许从最近保存的检查点继续训练，而不是从头开始。

**实现方式**：
1. 在`ray_train.py`中添加`--resume-from-checkpoint`和`--resume-checkpoint-path`命令行参数
2. 实现检查点加载和状态恢复逻辑
3. 支持模型状态、优化器状态和学习率调度器状态的完整恢复
4. 提供详细的使用文档和示例
5. 添加错误处理机制，确保在检查点加载失败时能够优雅地处理

## 2. 文件结构及功能说明

### 2.1 目录结构

```
F2LLM/
├── configs/                 # 配置文件
├── docs/                    # 文档文件
├── scripts/                 # 脚本文件
├── tests/                   # 测试文件
├── models/                  # 模型文件
├── data_tokenized_bert/     # 训练数据
├── cache/                   # 缓存文件
├── output/                  # 输出文件
├── arguments.py             # 参数定义
├── model.py                 # 模型定义
└── utils.py                 # 工具函数
```

### 2.2 核心文件功能说明

#### scripts/目录

- `ray_train.py`: 主训练脚本，包含训练流程控制和资源配置
- `ray_utils.py`: Ray训练工具函数，包括检查点保存/加载、损失计算等

#### configs/目录

- `ray_config.yaml`: 主配置文件，定义集群、训练和检查点配置
- `ray_cpu_test_config.json`: CPU测试配置文件
- `ray_mac_test_config.json`: Mac测试配置文件

#### docs/目录

- 设计文档、需求文档、测试计划和报告等

#### tests/目录

- 各类测试脚本，包括集成测试、检查点测试、集群测试、多GPU测试等

#### 其他重要文件

- `arguments.py`: 参数定义类，用于解析和管理训练参数
- `model.py`: 模型定义文件，包含F2LLM模型实现
- `utils.py`: 通用工具函数
